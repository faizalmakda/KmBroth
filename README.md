# KM Health

Website for **KM Health** — small-batch, halal bone broth, slow-simmered and
poured fresh each week in Manchester, UK.

## Status

Early design phase. `index.html` is the **landing page design shell** — a
static, self-contained page used to agree the look, feel and structure before
we wire up ordering, payments and the owner area.

Open `index.html` in any browser to preview.

## Planned scope

- **Storefront** — benefits, the weekly batch rhythm, shop, ordering. ✅ shell
- **Ordering** — cart + checkout (no card fees; bank transfer). ⏳
- **Payments** — bank transfer with a unique per-order reference so the owners
  can match incoming transfers to orders. Optional upgrade to Open Banking
  "Pay by Bank" for automatic reconciliation. ⏳
- **Weekly availability** — owners can open/close a week; when closed the shop
  shows *Sold out this week*. ⏳
- **Owner area** — private login to view orders, mark transfers received, and
  toggle the week on/off. ⏳

## Weekly rhythm

Orders Mon–Fri → brewed Saturday → shipped Monday → arrives Tuesday.
